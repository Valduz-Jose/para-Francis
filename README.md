# 💛 Para Francis

Una página web interactiva hecha con amor para una amiga especial que viajó de Venezuela a Chile.

🔗 **[Ver página en vivo](https://valduz-jose.github.io/para-Francis/)**

---

## ✨ ¿Qué es esto?

Un proyecto personal dedicado a Francis, compañera de equipo en el **Centro de Estudiantes de Ingeniería Informática** de la [UNET](https://www.unet.edu.ve/) (Universidad Nacional Experimental del Táchira). Cuando se fue a Chile, quise hacer algo más que un mensaje de WhatsApp.

---

## 🛠️ Tecnologías

- **HTML5** — estructura semántica
- **CSS3** — animaciones, variables, diseño mobile-first
- **JavaScript vanilla** — interactividad sin frameworks ni dependencias

Sin librerías externas. Todo desde cero.

---

## 🎨 Características

- ✈️ Avión animado que vuela por la pantalla
- 🌍 Mensajes de "vuelve pronto" en 8 idiomas
- 📸 Galería de fotos estilo polaroid con efecto de revelado
- 📓 Timeline de recuerdos compartidos en la UNET
- 💌 Animación de corazones y confeti interactiva
- 🎵 Reproductor de música minimalista
- 📱 100% responsive y mobile-first
- 🌅 Tema visual de atardecer venezolano

---

## 🚀 Correr en local

```bash
# Clona el repo
git clone https://github.com/valduz-jose/para-Francis.git

# Entra a la carpeta
cd para-Francis

# Abre con Live Server en VS Code, o con Python:
python -m http.server 8000
# → http://localhost:8000
```

> ⚠️ No abrir directamente con `file://` en el navegador, algunas funciones requieren servidor local.

## 💡 ¿Cómo fue construido?

El proyecto fue desarrollado usando **Claude Code** como asistente de desarrollo, con prompts iterativos para implementar cada sección. Todo el código fue revisado, ajustado y personalizado manualmente.
